# 能力矩阵

更新：2026-10-31，Asia/Shanghai。状态：现行。图例：**已实现**指默认产品有入口且经离线/隔离验收；**部分**指链路已通但仍有明确缺口或未完成真实验收；**未实现**指当前没有产品入口或明确返回不支持。

## 会话与模型

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| 流式对话、历史、停止、重启恢复 | 已实现 | DSH 唯一 transcript；停止不换 Session |
| 会话重命名、固定、归档/恢复 | 已实现 | 版本校验；归档拒绝新输入 |
| 会话分叉 | 已实现 | 原生已完成回合前缀；引用与来源依赖 |
| 会话删除、无痕模式 | 未实现 | 产品入口不提供 |
| 会话摘要与自动标题 | 已实现 | 后台模型开启时自动生成；手动标题优先 |
| 多连接、多模型、对话/后台路由 | 已实现 | 连接与模型引用保护；消息接纳时固定 |
| 计划模式、结构化问题、todo/goal、子代理、workflow | 已实现（原生挂载） | 长期任务质量与供应商差异另验 |
| 上下文压缩、工具结果裁剪、图片 offload | 已实现 | 原生 DSH 机制 |
| 签名安装包、全新机器安装演练 | 未实现 | 当前为源码安装 |

## 文件、材料与成果

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| 材料上传与文字提取 | 已实现 | TXT/UTF-16/GB18030、DOCX/PPTX 有限提取、XLSX 部分、PDF 前 100 页 |
| 图片输入 | 已实现 | 取决于当前模型声明的视觉能力 |
| 会话成果保存与下载 | 已实现 | 需本次提交明确保存许可；内容 ≤ 1 MiB |
| 授权目录只读、列表、搜索 | 已实现 | 最多 20 个目录；单文件 8 MiB；搜索有界 |
| 工作区文字写入 | 已实现 | 全局开关 + 本次保存许可；覆盖需匹配指纹 |
| Office/PDF 生成、扫描 OCR、完整表格语义 | 未实现 | 可由 Skill/MCP/插件补充 |
| 任意路径编辑或通用文件管理器 | 未实现 | 不等同于授权目录能力 |

## 说明

- “已实现”不等于所有供应商、显示器、账号或长期场景都已验收；具体边界见[验证](../reference/validation.md)。
- 未实现能力不由页面占位、文档描述或模型口头承诺代替；请求应明确返回不支持。
- 旧 OpenClaw/UFO 专有能力不因代码或历史文档保留而自动属于当前产品。
