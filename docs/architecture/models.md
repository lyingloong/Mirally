# 模型连接与能力

更新：2026-10-31，Asia/Shanghai。状态：现行。相关实现：`mirally/framework/model_connections.py`、`kernel/dsh/packages/mirally/mirally-product/src/models.mjs`、`model-probe.mjs`。

Mirally 不内置默认服务商、基础地址或密钥。用户需要在「设置 → 模型连接」自己配置服务与模型；没有模型时空会话只保留一个连接引导。

## 连接与模型

| 层级 | 内容 |
| --- | --- |
| 连接 | 名称、基础地址、API 格式、凭据；一个连接下的模型共享其服务和密钥 |
| 模型 | 模型 ID、显示名、视觉能力声明、推理档位、上下文窗口、最大输出、温度等生成参数 |
| 用途 | 对话路由 `chat` 与后台路由 `background` 分别选择默认连接 |
| 会话选择 | 每个会话可选择某个已配置模型或跟随默认；微信使用其所绑定会话的选择 |

- 支持 OpenAI Chat Completions、OpenAI Responses 和 Anthropic Messages 的原生适配；实际兼容性取决于所选服务。
- 可先保存连接，再从服务读取模型列表并选择添加，或手动添加。第一个模型成为该连接的默认模型。
- 模型声明的视觉、推理和上下文能力需要使用者核实；声明视觉不代表所有图片格式、截图或文档都能被理解。
- 消息接纳时固定所选连接与模型；运行中的配置受保护。改变默认路由或会话选择不改写已接纳的消息。
- 已被用途或会话引用的连接、模型不能直接删除；更换服务来源不暗中复用旧密钥。
- API Key 不回显，留空保留已有值，不写入浏览器存储。连接和模型只表示配置已保存，不表示服务已验证。

## 发现、探测与测试

- 模型列表读取、采用列表能力、保存配置和文字测试是不同操作。采用会更新待保存草稿；测试使用已保存连接，不偷偷保存表单。
- 服务探测和固定短文字测试都必须由用户明确发起，不发送已有会话、材料或记忆。
- 连接改动会使旧请求失效；测试失败显示真实错误，不伪装为空文字成功。
- 空配置不自动采用任何预设；DeepSeek 预设只在用户明确选择后填写地址、格式和模型。

## DeepSeek 实测范围

2026-10-25 使用用户已保存的 DeepSeek 官方连接，在隔离 home 中验证文字、流式、图片、推理档位和工具续轮。当前官方模型列表返回 Flash 与 Pro：Flash 声明文字与图片，Pro 仅文字；均声明 Low / High / Max 推理强度。能力随服务演进，应以实时列表和实际协议为准。

| 能力 | 结果 |
| --- | --- |
| 模型列表与能力声明 | 设置页按已保存连接读取并区分声明与实际测试 |
| Chat / Responses 文字与流式 | 两协议均返回正确结果 |
| 关闭推理 | Chat 与 Responses 显式关闭；不再以省略参数冒充关闭 |
| 推理档位 | Low / High / Max / 服务默认完成实际生成；Medium 对 DeepSeek 映射 High |
| 图片理解 | 本地生成的几何 PNG 识别正确；两协议从产品附件服务提交 |
| 推理与工具续轮 | 两协议在推理后调用文件成果工具，取得回执并核对下载字节 |

测试产生 API 用量；凭据、临时数据和日志不提交。此结果只证明对应连接、协议和测试内容，不代表其他供应商、所有模型或长期质量。

## 协议语义

- 显式 `reasoning_effort` 优先于旧 `reasoning_enabled`。空串仅用于旧配置兼容；显式 `default` 才遵从服务默认。
- Chat 使用 DeepSeek 的 `thinking.type` 与 `reasoning_effort`；Responses 使用 `reasoning.effort`。推理工具历史通过原生块和协议回放保留，不只保留最终正文。
- 图片开关声明当前连接可接收图片，不会让纯文本模型获得视觉能力；切换模型后不沿用上一个模型的视觉声明。
- 上下文窗口参与会话预算；最大输出包含服务计算的推理输出，过低可能没有最终回复。列表最大值是服务上限，采用模型不会擅自把用户输出预算提高到上限。
- 协议字段映射和推理显示只覆盖已实测的 DeepSeek 路径；其他 OpenAI 兼容中继可能需要自己的参数约定。

## 未覆盖

供应商独立 Files、Search/Fetch、FIM、前缀补全，第三方代理的兼容性，以及所有模型的视觉/推理/工具表现，未在本轮完整接入或验收。模型质量、延迟和长期任务成功率不能由短用例保证。网页搜索/正文读取是可单独开启的产品能力，默认关闭并可能产生费用，见[系统概览](overview.md)。
