# 会话与作业

更新：2026-10-31，Asia/Shanghai。状态：现行。相关实现：`mirally/framework/service.py`、`kernel/dsh/packages/mirally/mirally-product/src/`。

会话是 Mirally 的通用协作单位：讨论、执行、查看进展、追问和从微信继续，都使用同一逻辑会话和同一份 DSH 历史。产品不要求用户先创建工作或项目记录。

## 数据模型

```text
Conversation（产品身份、标题、固定/归档、模型选择）
  └─ Generation（当前代次）
       └─ DSH Session（唯一 transcript 与工具事实）
```

- 产品库只保存逻辑会话、代次引用、命令回执和业务状态，不复制聊天正文。
- 普通停止取消原生当前回合和待处理输入，保留同一 Session、同一代次和完整历史；后续输入可继续使用文字、工具和图片。
- 撤回数据来源、变更扩展等边界会隔离旧代次并在新输入时建立新代次。早期已经分裂的多代档案不自动重写；只对仍有效来源提供保守文字续接，旧工具结果和附件不会自动回到当前上下文。
- 启动恢复会核对原生历史与作业回执，不盲目重放旧输入、脚本或桌面动作。

## 会话操作

| 操作 | 行为 |
| --- | --- |
| 新建 | 首次输入前不创建多余空会话；历史与新会话都在侧栏按最近活动排列 |
| 重命名 | 用户手动命名优先，自动标题不会覆盖；并发版本冲突保留草稿并提示刷新 |
| 固定 | 固定项保留在会话列表顶部；置顶与最近活动分别排序 |
| 归档/恢复 | 归档拒绝新输入；有活跃命令时先停止再归档；归档只改元数据，不删除 DSH Session |
| 分叉 | 使用原生已完成回合前缀创建独立 Session，记录父会话、前缀边界和来源依赖；重试只创建一次 |
| 删除/无痕模式 | 当前产品入口未提供；请求明确返回不支持，不伪装成功 |
| 选择模型 | 可按会话选择已配置模型或跟随默认；消息接纳时固定所选连接与模型，运行中配置受保护 |

## 后台作业

会话可以直接使用两类执行事实：

1. **DSH 原生作业**：原生 shell/后台任务、工具调用与子代理，由 DSH 持有进程、输出和状态。
2. **Mirally 会话命令**：产品命令接口在会话中执行 PowerShell、受管理后台进程等，遵守 ActionGate 审批与停止范围。

两者的共同约定：

- 作业有独立的创建者、所属会话、真实执行身份、阶段、输出和终态；进程状态与输出以执行器为准，不能用会话摘要或模型推测代替实时进度。
- 用户可以查询作业状态、近期输出并请求停止；停止回复只停止当前模型回复，不自动停止后台作业，反之亦然。
- 用户明确要求时，可登记作业结束通知，复用已启用的桌面/微信提醒渠道。登记只在当前宿主运行期间有效，不跨重启恢复。
- 受管理进程随宿主退出结束；已脱离的进程不保证被终止。重启后应重新查询真实状态，不自动重跑结果不明的动作。
- 外部系统里的实验、训练或服务只有通过明确工具或来源才能读取；能读日志不等于拥有停止或修改它的权限。

微信助理可以在用户明确要求时查询会话所属作业，并向原会话委托后续指令；委托沿用同一动作审批。见[消息渠道](channels.md)。

## 快捷开始

原工作准备页保留为「快捷开始」：用户选择材料、填写要求、选择输出方式后，内容进入当前或新会话。它只是帮助组织输入，不会创建独立工作 owner、后台运行或第二套 Agent；未发送的草稿和材料仍属于原会话。

## 摘要与自动标题

会话摘要是供人和微信助理浏览的历史投影，不是实时任务状态，也不能代替作业输出或命令结果。

- 摘要基于会话当前代最近 30 条文本消息生成；无法完整读取历史时不生成，旧代及附件不会被隐式传给摘要模型。
- 摘要记录其代次和命令版本；更新期间出现新消息、会话冻结、归档或来源撤权时拒绝写入。生成后的新消息把摘要标记为过期。
- 自动标题在首次成功生成时替换基于首条消息的本地后备；用户手动命名始终优先，已生成标题不会每轮变化。
- 自动生成仅在后台能力开启时进行，最多每会话每十分钟一次、全局每天十二次，独立于记忆语义整理预算。用户主动生成使用设置中的后台模型，可能产生费用。
- 桌面 `POST /api/sessions/{id}/recap` 返回操作状态；`GET /api/sessions` 的 `recap` 返回正文、时间与过期标记，未生成时为 null。微信助理可读取或在明确要求时刷新。

摘要失败不影响消息发送；无后台模型、来源撤销、历史缺失或模型失败都不会伪装为成功。

## 明确边界

- 一个逻辑会话同时只有一个活动推理回合；新输入按产品与 DSH 的队列语义处理，不能靠并发写入制造第二份历史。
- 会话、作业和审批都绑定当前代次与来源状态；解绑、归档、撤权或停在旧回执上的操作不能继续执行。
- DSH 原生 `todo`、`goal`、`workflow` 和子代理已挂载，但挂载不等于长期任务质量、跨重启恢复或所有供应商行为均已验收。
- 后台进程、浏览器和桌面观察的停机语义不同：退出宿主会结束自己拥有的进程和窗口，不撤销已经发生的外部效果。

验证命令与未覆盖范围见[验证](../reference/validation.md)。
