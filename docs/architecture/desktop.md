# 桌面与伙伴

更新：2026-10-31，Asia/Shanghai。状态：现行。相关实现：`mirally/framework_shell.py`、`mirally/framework_host.py`、`mirally/assets/control-ui-*`。

桌面入口复用原 Mirally 的开屏、主题、窗口呈现和伙伴体验，同时由自有 Host 提供产品页面。浏览器模式只保留页面形态，不提供原生裁剪、置顶、伙伴窗口或本机截图。

## 启动与窗口

- 首次显示等待开屏页面首帧绘制完成，再显示窗口，避免 WebView2 初始化期间先露出深色底板；就绪后直接进入工作台，不额外等待动画播完。
- 开屏使用「相伴 M」、两束环绕光带、柔光和粒子动画，标语为「与你并肩，让想法向前。」；遵守系统减少动态效果偏好。加载失败显示可操作的错误和重试入口。
- 原生窗口保留 Windows 拖动、最小化、最大化、关闭、任务栏图标和窗口菜单；`Alt+Space` 或点击标题栏图标打开系统菜单。
- 主窗口、伙伴和浮层使用原生裁剪与非矩形命中区域；浏览器中只有矩形页面，不能调用窗口置顶、裁剪或桌面截图。

## 三种伙伴形态

| 形态 | 进入方式 | 行为 |
| --- | --- | --- |
| 侧栏 | 侧边入口、进入伙伴 | 显示当前任务、步骤和快速输入；可展开完整面板 |
| 图标 | 单击侧栏底部图标 | 打开紧凑对话气泡并固定 |
| 桌宠 | 切换造型 | 保留海獭/飞狐、呼吸、眨眼、挥手、爱心和工作状态；可拖动，悬浮不自动弹窗 |

交互约定：

- 鼠标停留约 140ms 显示轻量预览，离开后留约 400ms 宽限；预览不抢焦点，可以移入输入区。
- 点击、键盘 Enter/Space 或输入/添加材料后保持展开；固定按钮切换保持状态。
- 「收起」返回边缘入口并保留草稿与材料；Escape 同样收起，焦点回到入口。
- 「返回主窗口」恢复用户原来的正常尺寸、位置和最大化状态；「最小化到任务栏」是真正的 Windows 最小化，不是退出或停止工作。
- 形态与造型沿用已有产品偏好；固定状态只属于本次交互，不是新的全局后台开关。

## 关闭、托盘与退出

「设置 → 通用 → 桌面窗口 → 关闭主窗口时」保存 `mirally.window.closeBehavior`，可选隐藏到托盘或退出。

- 有可用托盘时默认隐藏窗口；单击托盘图标恢复同一窗口和伙伴形态，右键提供退出。
- 托盘不可用时关闭窗口会退出。
- 从托盘或设置页明确「退出 Mirally」会停止窗口、自己连接的 Host 和后台，包括复用已有宿主的情形；已完成的外部效果不会因此回滚。
- 关闭原生窗口的默认行为是隐藏到托盘，Host、微信连接和后台作业继续；若设置为关闭即退出，则按明确退出处理。关闭浏览器标签页不等于停止 Host。
- 伙伴与主窗口共用同一会话、草稿和材料；切换形态不创建第二份历史。

## 截图与捕获排除

- 桌面截图只能由输入区的截图手柄明确拖动发起；先显示预览，用户确认后才作为材料发送。浏览器模式提示改为添加图片文件。
- 「设置 → 通用 → 桌面窗口 → 截图/录屏时隐藏伙伴」保存 `mirally.companion.hideFromCapture`，默认开启。保存后立即应用到已展开的伙伴。
- 该开关使用 Windows `WDA_EXCLUDEFROMCAPTURE` 排除伙伴窗口；是否生效取决于 Windows 版本和采集软件是否遵守。主窗口保持普通捕获行为；用户主动拖动截图时会临时隐藏伙伴以免遮挡目标。
- 普通悬浮或伙伴待机不采集桌面；活动采集是独立能力，见[活动数据层](activity.md)。

## 主题与文字

晴空蓝、深色和跟随系统等原外观页面继续保留，界面偏好由产品 home 持久化。文字角色、字号与缩放遵循[视觉基线](../standards/ui-visual-system.md)；伙伴窗口的独立密度和几何在真实桌面验收时单独检查。

## 验证

```powershell
.\.venv\Scripts\python.exe tools\verify_framework_shell.py
.\.venv\Scripts\python.exe tools\verify_framework_shell.py --close-exit
.\.venv\Scripts\python.exe tools\verify_framework_shell.py --page-quit --reuse-host
node tools\verify_companion_interaction.mjs
```

GUI 验证必须顺序运行，只操作自己创建的窗口和隔离数据。不同显示器、DPI、长期使用和外部截图软件仍需真实验收。
