# 对话记事本

在桌面或微信说“记一下，今天给海獭换了水”，或“找一下这周记的海獭换水”。记录随产品数据保存在本机。能按日期、标签、关键词或目录查找，也能修改、撤销、删除、移动记录及改名或归档目录。

## 写入与查询

当前用户回合明确要求写入后，记事工具再使用现有动作审批。意图有歧义时先澄清，普通聊天无需操作。目录和标签可以随记录建议。日期按产品时区解释，无法确定的事件时间留空。更正和撤销写入修订，删除后从正常查询中排除。查询返回匹配总数和可核对的片段。按记录 ID 查看详情时，可以读取该条正文和近期修订。

默认查询排除私密记录。桌面和微信都需要用户当次明确要求才包含私密记录。模型可以标记私密内容，产品层也会识别常见敏感文本。私密标记只影响可见性。贴进聊天的凭据已进入聊天链路，记事本不提供凭据保险箱或加密。

## 模块边界

[DSH 记事工具](../../kernel/dsh/packages/mirally/mirally-product/src/notebook-tools.mjs)连接用户回合、动作审批和当前渠道权限。[Python 记事 owner](../../mirally/framework/notebook.py)通过内部调用读写产品 SQLite，持有记录、目录、修订、幂等和过滤规则。记事记录按查询返回，不参与自动记忆召回。首版由桌面和微信对话使用，账本、导出和跨设备同步留待后续。
