# 对话记事本

在桌面或微信说“记一下，今天给海獭换了水”，或“找一下这周记的海獭换水”。记录随产品数据保存在本机。能按日期、标签、关键词或目录查找，也能修改、撤销、删除、移动记录及改名或归档目录。

## 写入与查询

当前用户回合明确要求写入后，记事工具先生成安全预览，再使用现有动作审批。同一条请求明确取消保存时停止操作，意图有歧义时先澄清。审批显示非敏感正文、变更字段和影响，并隐藏私密内容及新建私密目录的名称。同一回合中原样重试已完成的写入会返回原回执。目录和标签可以随记录建议。日期按产品时区解释，无法确定的事件时间留空。更正和撤销写入修订，删除后从正常查询中排除。查询返回匹配总数和可核对的片段；省略目录筛选表示所有目录，显式指定未分类只返回无目录记录。按记录 ID 查看详情时，可以读取该条正文和近期修订；历史摘要可分页，指定版本可读取完整旧正文。

默认查询排除私密记录。桌面和微信都需要用户当次明确要求才包含私密记录。模型可以标记私密内容，产品层也会识别常见敏感文本。私密标记只影响可见性。疑似凭据默认在审批前拒绝写入；用户当次明确要求按普通私密记事保存时才可写入，并在审批中隐藏内容。贴进聊天的凭据已进入聊天链路，记事本不提供凭据保险箱或加密，应尽快更换。

## 导出

当前用户消息开头明确要求导出或备份时，记事工具调用只读的 `notebook.export`，把有效记录按目录和记录时间整理成一份 Markdown（标题、事件与记录时间、标签、正文，未分类单独分组），生成一个可下载文件，与写入其它会话成果使用同一 1 MiB 上限；桌面可直接下载，微信按既有成果回传发送。本次提交未开启成果保存时，导出先经现有同回合动作审批申请保存许可（桌面确认，微信按确认码回复），未获批准、来源或微信授权失效时不生成文件；仅提问或记事内容里提到导出不会触发。默认只导出公开记录，同一回合明确要求后才包含私密记录，并在文件头标注；可识别的凭据记事一律不写入导出文件，文件头与回执如实写明排除条数；超过单次条数或字节上限时文件仍会生成，文内写明截断和未导出条数。空记事本或全部内容都被排除时返回明确空结果，不生成空文件。导出不含聊天原文或来源原话；私密标记仍只用于筛选，不是加密。

## 模块边界

[DSH 记事工具](../../kernel/dsh/packages/mirally/mirally-product/src/notebook-tools.mjs)连接用户回合、安全审批预览和当前渠道权限，并提供历史摘要、指定版本读取和成果导出。[Python 记事 owner](../../mirally/framework/notebook.py)通过内部调用读写产品 SQLite，持有记录、目录、修订、幂等和过滤规则。记事记录按查询返回，不参与自动记忆召回。首版由桌面和微信对话使用，账本和跨设备同步留待后续。
