Use case: ui-mockup
Asset type: polished desktop product interaction concept board for OpenAssist, a Windows personal AI assistant
Primary request: Design an exceptionally refined, feasible desktop companion that transforms from a full conversation workspace into a compact floating card attached to the right screen edge while it works. When a user approaches the card, it expands into an elegant input panel so they can add instructions during a task. Convey continuous conversation and visible acknowledgment of user instructions. This is a high fidelity product design, not science fiction art.
Composition: One wide landscape concept board with three clearly separated, carefully aligned scenes, left to right: full conversation workspace; compact edge companion on a spacious desktop; expanded edge companion ready for a follow-up instruction. Each scene uses the same coherent visual language. Small simple state labels above scenes: "WORKSPACE", "WORKING", "ADD A NOTE". Use the largest region for the compact and expanded floating states so their shape and proportions are unmistakable. Show the desktop behind as a softly defocused neutral file workspace with no personal data.
Design: Quiet mineral white, near-black forest typography, restrained sage green accents, precise spacing, rounded soft rectangular forms, delicate borders, subtle diffuse shadows, very crisp and legible type. Premium calm technology, investor-demo quality. Opaque light surfaces with a little dimensional separation, no transparent text or busy glass effects. White space does the work. Avoid neon, purple gradients, large glowing orbs, decorative charts and dashboard clutter.
Workspace: An elegant header "OpenAssist", small session indicator "同一会话 · 记得前面的任务", a strong lyrical current-action title "正在整理本周资料", a small prior context reference, a clean composer and calm controls. Clear hierarchy with one primary action.
Compact working state: A small horizontal card, roughly 260 by 112 logical pixels, anchored at the right edge around the upper third of the desktop, rounded on its exposed left corners, much smaller than the desktop and never centrally obstructive. Show only a small brand mark, "OpenAssist", "正在整理资料", "第 3 步", and a restrained green activity line or pulse. The edge attachment should look intentional and beautiful, like a precise physical tab extending from the monitor edge. No spurious completion percentages.
Expanded state: The same right-edge card expands smoothly leftward and downward, staying anchored to the same point, about 370 by 300 logical pixels. Show a current action header, one compact receipt "已收到 · 下一步将调整", the user note "只整理 PDF，保留原文件", a live composer labeled "随时补充你的想法", a send arrow, and small pause / stop controls. Show an unobtrusive cue of hover expansion without a giant mouse cursor. It is visibly a personal assistant with memory, not a notification banner.
Constraints: Exact product name OpenAssist. Keep Chinese text as quoted where possible, no gibberish filler paragraphs. Use a consistent type family and unified palette across all scenes. Do not claim completion of actual work. No watermark. This image is a visual design reference for implementation with native desktop UI.
