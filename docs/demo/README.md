# 办公协作材料与核对步骤

这里保留两份合成材料：[会议纪要](meeting-notes.md)与[项目背景](project-background.md)，用于检查材料理解、产物和后续修改。它们不是独立演示程序。

1. 从 `python -m mirally`、默认 `run.ps1` 或 `run-openclaw.ps1 mirally` 打开当前工作台，新建普通主 Agent 会话。
2. 添加两份材料，要求整理一份汇报与一份待办清单，保留冲突、来源和未确认事项。
3. 在原生工具记录中确认实际读取材料；通过 Files 或文件管理器打开输出，核对内容来自本次输入。
4. 提出一个具体修改要求，检查输出确实变化；发送回执不等同于最终完成。
5. 如使用侧边伙伴，核对它与工作台的会话、草稿、附件和实际任务状态一致。

本流程使用当前配置的模型，可能产生服务费用；没有独立模拟入口。不因界面显示已保存就认定真实文件存在。后台文件/浏览器任务与 UFO 当前桌面执行分开验证，后者由主 Agent 委派内部子代理。

完整体验核对见 [功能清单](../mirally-feature-checklist.md)，生命周期见 [桌面套壳](../openclaw-desktop-shell.md)。旧演示的截图和本地报告仅是对应版本的历史证据，不代替当前验收。
