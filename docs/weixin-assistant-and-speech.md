# 微信助理与语音

设置 → 消息渠道 → 微信可选择「直接会话」或「助理」。微信发送“助理”或 `/assistant on` 进入助理，发送“会话模式”或 `/assistant off` 返回之前选择的直接会话；也可继续使用现有的会话、工作和日程命令。普通自然语言进入当前模式的会话，不经过额外分类模型。助理可查找、查看会话和工作，在用户明确要求时向目标原会话发出委托并等待其真实回复；目标不明确时应先询问。委托需要打开微信远程控制，目标中的动作继续使用微信的审批策略。原会话保存自己的上下文和微信来源，助理有自己的独立上下文。切换模式不支持中断正在执行的微信回合。

微信中可发送文字、语音、图片、文件和视频。平台提供语音转写时直接使用；否则下载并解码，再由共同的语音服务识别。图片和文件进入当前会话的材料处理，模型是否能理解取决于模型视觉能力和文件的实际提取结果；视频作为文件保存，不代表已解析视频。单项媒体上限 8 MiB，每条最多 12 项；不支持的编码或解析失败会说明失败，不提交部分文本。打开微信远程控制后，可明确要求 Mirally 将当前会话已保存的成果文件发到微信；图片与可识别的视频按对应媒体发送，其余按文件发送。助理可委托原会话发送该会话的成果。发送有持久回执，未确认的发送不会自动重发；语音回复尚未接入。账号及客户端对媒体的实际表现仍需实机确认。

桌面对话输入区可点击麦克风开始录音，再点击停止；识别结果追加到草稿，由用户自行检查和发送。切换会话或离开输入区会取消正在进行的录音或识别；不是常驻监听。微信和桌面共用独立语音识别设置，与聊天模型分开配置；DeepSeek 聊天 API 不自动等于语音识别服务。前往设置 → 通用 → 语音识别，填写兼容 OpenAI 音频转写接口的服务地址、模型和密钥，或选择本地 Whisper。云服务会接收录音内容。

本地识别需要先安装依赖并自行准备兼容 faster-whisper 的本地模型目录，配置选择该目录；不会自动下载模型：

```powershell
.\.venv\Scripts\python.exe -m pip install faster-whisper
```

录音在识别期间写入系统临时目录；正常完成、取消和退出会尽力删除临时文件，系统或进程异常终止时无法保证清理。语音设置保存在本机产品目录，Windows 的语音密钥使用当前用户 DPAPI 保护，迁到另一用户或机器后需要重新填写；勿提交或共享本机配置。首次使用麦克风需要系统和宿主授予权限，实际设备及微信账号的兼容性以实测为准。微信输入状态可在渠道设置关闭，不代表消息已读或任务已完成；进入微信聊天界面的事件目前不可用，不能可靠地主动提示用户打开了聊天。
