# 手机端会话使用说明

微信是默认的手机入口，不需要自建云服务器。电脑保持 Mirally 运行并连接微信后，发送自然语言给微信助理，即可查找会话、询问实际后台作业状态，或要求目标原会话继续处理。助理通过原会话执行，使用原有上下文和桌面相同的动作权限。可发送“菜单”查看会话与日程指令，列表选择使用最近一次成功送达的数字编号。

普通会话可通过通用命令和后台作业执行任务；实际进度需要来自进程输出、日志或所查询的外部系统。用户可以要求作业结束时通知，Mirally 复用已启用的提醒渠道；登记仅在宿主运行期间有效。当前受管理进程随宿主退出结束，不承诺跨重启恢复。完成一次模型回复不等于后台任务结束。桌面休眠、退出或断网时无法接收微信指令或即时发送通知。

可选手机网页在设置的消息渠道页面配对，提供会话、消息和显示偏好；异地访问需要自行准备私人 HTTPS 转发。手机网页拥有独立且有限的操作范围，不等同于完整桌面控制面。取消配对会撤销该设备的访问。两种手机入口都使用同一 Mirally 会话历史，不另建模型会话。

日历、提醒和定时执行见[日历与定时能力](calendar-and-scheduling.md)，微信助理与多媒体能力见[微信助理与语音](weixin-assistant-and-speech.md)。
