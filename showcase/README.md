# Mirally — Everyday Ally 展示站

中文产品与愿景展示站，面向内部演示及产品交流。独立于 Mirally 产品运行时，不需要模型配置、API Key、Gateway 或活动数据库。

## 运行

需要 Node.js 20.19+ 或 22.12+ 的受支持版本及 npm。在本目录执行：

```powershell
npm ci
npm run dev
```

按终端提示打开本机地址。端口可指定，例如 `npm run dev -- --port 4173`。默认仅绑定 `127.0.0.1`。

## 构建与展示

需要发给别人、在另一台电脑上直接双击打开时，导出单文件离线版：

```powershell
npm run export:html
```

输出为 `exports/Mirally.html`。只需复制这一个文件，用 Edge、Chrome、Firefox 或 Safari 等现代浏览器打开；无需安装 Node.js、启动服务或连接网络。图片、字体、样式和脚本均已内嵌，保留场景切换、预设问答、来源展开和摘要下载。“关于这份展示”中可下载随文件内嵌的素材说明与完整许可。

源码或图片修改后重新运行导出命令。`exports/` 是可再生成的交付产物，不纳入 Git。

需要部署网站时，仍使用常规构建：

```powershell
npm run build
npm run preview
```

`dist/` 是完整静态站，可部署到静态托管服务，也支持部署到子目录。不要直接双击 `dist/index.html`；浏览器模块需要 HTTP 静态服务。构建文件、图片与字体都在本地，无需外部 CDN。

跨机器或换目录时，只需复制本目录的源码与 `public/`，运行 `npm ci` 重新生成依赖，再构建。不要复制 `node_modules/`。不需要主项目的 Python 虚拟环境或私有配置。

## 页面与互动

页面按五章展开：

1. **认识 Mirally**：Everyday Ally 定位与 Ally 的含义，首屏可切换日间、夜晚。
2. **应用场景**：通过“场景演示”导航进入，切换工作场景、活动记忆、生活陪伴。用全宽画面与简短对话展示会议整理、记录查找、画面问答。
3. **当前能力**：用 HTML/CSS 绘制三种界面示意：左侧文档与右侧对话、任务步骤与生成文件、带来源的活动摘要时间线。中等宽度使用横向卡片，手机使用上下排布。
4. **长期愿景**：从桌面能力，走向多模态交互、跨场景与跨设备陪伴。
5. **商业路径**：个人与团队工作室照片配合三条路径，内容始终可见，不需要展开阅读。

桌面（宽度至少 1000px、高度至少 700px）和窄展示窗口（宽度至少 480px、高度至少 800px）使用原生 CSS 滚动停靠，让每章按窗口可用高度排布。保留浏览器正常的滚轮、触控与键盘滚动，不拦截滚轮事件。更窄或更矮的窗口使用普通连续滚动，内容可自然增长。

- 工作与记忆演示使用同一组虚构会议资料。工作场景以 AI 生成的电脑界面为背景，叠加可交互的 Mirally 对话与会议笔记，提问后展开行动清单；记忆场景展示对应活动记录。
- 工作演示可下载浏览器本地生成的 Markdown 会议摘要；记忆演示可展开预置资料来源。
- 娱乐演示使用虚构剧集人物卡及不剧透的关系说明，属于未来体验构想。
- 移动端导航、键盘 tabs、对话收起与重开、来源说明对话框。
- 尊重系统“减少动态效果”设置。

所有演示资料均为虚构。页面不访问桌面、活动数据或模型 API，不把概念演示视为已实现能力。

当前能力卡片采用静态界面示意，不是产品截图。此前生成的三张能力场景照片不再用于这些卡片，素材与提示词保留为生成历史。

## 修改入口

| 文件                                | 内容                                       |
| ----------------------------------- | ------------------------------------------ |
| `src/App.jsx`                       | 主页面、导航、品牌文案与愿景               |
| `src/style.css`                     | 主视觉、响应式与动效                       |
| `src/chapters.css`                  | 五章窗口适配、原生滚动停靠、小窗口自然排版 |
| `src/CapabilityVisual.jsx`          | 当前能力的三种静态界面示意                 |
| `src/capability-visuals.css`        | 能力界面样式与卡片适配                     |
| `src/DayExperience.jsx`             | 三段交互脚本与下载                         |
| `src/day-experience.css`            | 场景窗口与演示样式                         |
| `public/images/`                    | 已生成的 WebP 宣传素材                     |
| `image-prompts/`、`IMAGE-BRIEFS.md` | 生图提示词与实际生成记录                   |
| `public/CREDITS.md`                 | 素材来源与演示边界                         |

`package-lock.json` 锁定依赖版本；正常展示不发生付费 API 请求。

如需恢复指定版本，在仓库根目录执行（下面以五章版本为例）：

```powershell
git restore --source=65fb10d2 --worktree -- showcase
```

此命令会丢弃 `showcase/` 中相对于所选版本的后续工作区修改，不影响其他目录，也不改写 Git 历史。执行前先提交或另存需要保留的新版内容，恢复后重新运行构建。所选版本中不存在的新增文件需要单独检查和处理。
