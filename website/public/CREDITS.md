# Mirally — 展示说明与素材来源

本页是一份产品与愿景展示，包含预设的交互概念演示。不会访问用户的桌面、活动数据、模型服务或 API 凭据。

## 品牌

Mirally 相伴 M 标识来自主仓库 `mirally/assets/`，保持现有品牌形态。

## AI 宣传图

日间工作、夜晚生活、海岸愿景、虚构剧照与工作桌面背景于 2026-10-15 使用 `gpt-image-2` 生成；夜景以日间图为参考，保持人物和空间的连续性。工作桌面中的浏览器、照片和日历属于示意背景，Mirally 对话与笔记卡由网页单独渲染。页面里的角色、剧集、情境与资料均为虚构。视觉场景不代表已实现全部产品能力。

首页现以市集资料或虚构剧集画面配合 HTML/CSS 侧边对话展示工作与生活体验，原日间、夜晚家居照片不再用于首页，保留为生成历史。首页市集图 `hero-market-detail.webp` 裁自 `work-desktop-ai.webp` 的矩形区域 `(74, 141, 771, 535)`，尺寸为 697 × 394；这是本地裁剪，未新增生图或 API 请求。

商业路径的工作室照片也由同一模型生成，现保留为生成历史，不再用于商业路径章节。该章改用 HTML/CSS 产品图解呈现个人、团队和服务的商业规划，不是已发布团队或服务功能的产品截图。活动记忆中的场地与海报缩略图裁自工作桌面背景，与演示资料对应。所有生成的人物与场景均非真实客户或合作伙伴背书。

“当前能力”的侧边对话、任务执行与活动记忆卡片使用 HTML/CSS 绘制静态界面示意，不是产品截图。此前由同一模型生成的三张能力场景照片已不再用于卡片，素材与提示词保留为生成历史。

“下一步能力”中的语音交流、主动协助与个性化协作使用 HTML/CSS 概念示意，标记为“近期开发方向”，不代表已发布功能。

图像通过 imagegen 官方 CLI/API 工作流生成，完整提示词与生成记录在源码的 `image-prompts/` 和 `IMAGE-BRIEFS.md`。网页只加载本地保存的图片，不连接生图 API。

## 内容边界

“当前能力”依据产品主仓的 README、CHANGELOG 与能力矩阵描述现有能力。当前产品支持截图提问；生活场景中的虚构角色识别及不剧透关系说明仍是概念体验。语音交流、主动协助与个性化协作展示近期开发方向，跨设备陪伴与更广泛的服务连接展示长期愿景。

演示会议摘要由浏览器本地生成，明确标注演示数据。页面未接入统计、追踪、登录或支付功能。
