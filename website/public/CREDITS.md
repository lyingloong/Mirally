# Mirally — 展示说明与素材来源

本页介绍正在开发的 Mirally，包含开发版界面截图和预设交互演示。新版首页当前为待反馈的预览方案；页面本身不会访问用户的桌面、活动数据、模型服务或 API 凭据。

## 品牌

Mirally 相伴 M 标识来自主仓库 `mirally/assets/`，保持现有品牌形态。

## 开发版界面截图

首页主图 `images/product-desktop.webp` 来自隔离运行的 Mirally 开发版界面，使用本地模型 fixture 与预设会话资料。截图展示真实产品页面，内容属于演示数据，不来自真实用户会话；也不代表真实外部模型、微信或桌面动作已经通过验收。网页仅加载保存的图片，放大操作不连接产品宿主。

## 预设交互演示

工作、记忆和生活三个标签页使用 HTML/CSS 界面与预设资料、回答，属于交互示意，不是产品运行实录。人物、市集活动与剧集均为虚构。生活演示中的角色识别与不剧透关系说明属于未来概念，不能当作已发布功能。

演示会议摘要由浏览器本地生成，下载内容明确标注演示数据；它不是现场会议或模型生成结果。记忆演示中的场地与海报缩略图裁自历史 AI 工作桌面背景，与虚构资料对应；生活演示使用历史生成的虚构剧照。

## 历史 AI 素材与页面取舍

日间工作、夜晚生活、海岸愿景、虚构剧照、工作桌面背景及工作室照片于 2026-10-15 使用 `gpt-image-2` 生成；夜景以日间图为参考，保持人物和空间的连续性。工作桌面中的浏览器、照片和日历属于示意背景，原 Mirally 对话与笔记卡由网页单独渲染。所有生成的人物与场景均非真实客户或合作伙伴背书。

新版首页移除原六章叙事中的重复 Hero、独立能力示意、愿景大图与商业路径章节，以产品截图、三个特点和一处交互演示介绍项目。后续方向保留简短文字，个人、团队与服务的商业规划不作为当前能力呈现。旧日夜家居图、海岸愿景图、工作室照片及能力场景照片保留为生成历史，不代表本版首页仍在使用。

原首页市集图 `hero-market-detail.webp` 裁自 `work-desktop-ai.webp` 的矩形区域 `(74, 141, 771, 535)`，尺寸为 697 × 394；这是本地裁剪，未新增生图或 API 请求。历史能力卡片及商业路径图解使用 HTML/CSS 绘制，也不是产品截图。

历史图像通过 imagegen 官方 CLI/API 工作流生成，完整提示词与生成记录保留在源码的 `image-prompts/` 和 `IMAGE-BRIEFS.md`。网页只加载本地保存的图片，不连接生图 API。

## 内容边界

产品特点依据主仓的 README、CHANGELOG 与能力矩阵描述现有能力，实际可用范围以产品实现与验证记录为准。当前产品支持截图提问，不能据此推定生活演示的角色资料、关系检索或陪伴体验已完整实现。后续记忆、主动协助与日常任务的连接仍是开发方向。

页面采用中文正文与英文品牌标题，尚未实现中英文切换。页面未接入统计、追踪、登录或支付功能。
